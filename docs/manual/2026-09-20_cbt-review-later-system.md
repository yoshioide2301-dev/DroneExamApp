# 技術履歴: CBT模擬試験「あとで見直す」＆見直しフィルター（パターンB）

最終更新: 2026-09-20

## 概要
`index.html` のみ変更。CBT模擬試験（本番・ミニ）の実行画面で、問題番号マス目（`#cbtJump`）の真上に `.cbt-review` エリアを新設し、2つのトグルを配置。外部ライブラリ・外部通信なし。`cbt_exam_history`・誤答ID管理・SVGグラフ・ブートキャンプ・再開ポップアップの既存挙動は変更なし。

## 1. UI / ロジック
- **🚩 あとで見直す（`#cbtFlagBtn` / `toggleCbtFlag()`）**: 現在の設問のチェックをON/OFF。ON時はミントグリーン（`#a8e6cf`）で発光（box-shadow）し、ラベルが「見直しチェック中（解除）」に変化。
- **🔍 見直し対象のみ表示（`#cbtFilterBtn` / `toggleCbtFilter()`）**: ONでチェック済み問題のみを巡回対象に。ON時、現在問題が未チェックなら最寄りのチェック済み問題（後方優先）へ自動移動。チェックが0件の間はONにできずトースト表示。
- **フィルター中の前へ/次へ（`moveCbt()` / `cbtFlagStep(d)`）**: チェック済みだけをスキップしながら移動。前後にチェック済みが無い側のボタンは `disabled`。マス目タップでの直接ジャンプは従来どおり自由。
- **マス目連動**: `renderCbtQuestion()` が `cbt.flags[i]` に応じて `.flag`（背景 `#a8e6cf`）を付与。解除で即座に回答済み(`done`)/未回答の通常色へ戻る。現在位置のオレンジ枠（`cur`）は維持。
- 状態: `cbt.flags`（問題ごとの真偽配列）、`cbt.filter`（表示フィルター）。

## 2. レジューム統合（`drone_exam_resume_state`）
- CBT保存時に `flags:[bool...]`（出題IDと同じ長さ）を追加（`saveResumeState()`）。それ以外の構造は不変。
- `loadResumeState()` が `flags` の配列長・型を検証。無い/不正な場合（旧形式のセーブ含む）は全て未チェックで安全に復元。`beginCbtSession(questions, index, flags)` が復元し、マス目のミント状態も再現。
- 破棄: 試験終了（`finishCbt`）・中断（`abortCbt`）・ポップアップの破棄で従来どおりセーブごと削除されるため、見直しフラグも同時に消える。
- 保存しない項目: フィルターのON/OFF（再開時はOFF）。回答内容・残り時間も従来どおり非保存（再開時のタイマーは新規）。

## 3. 検証（疑似DOMでのモック、一等・二等それぞれ実施）
`<script>` 全ブロックの構文チェックOK。以下が全PASS（計33項目、失敗0）:
- チェック→マス目がミントに（[2,7,20]）／解除で通常色に復帰／ボタンの発光ON
- フィルターONでチェック済みのみ巡回（次へ 2→7→20、前へ 20→7→2、末尾で無効化）、OFFで通常移動に戻る
- セーブに `flags` が保存され、再起動ポップアップから復元すると資格・問題番号・チェック状態・ミント表示が100%再現
- 終了・中断でセーブ破棄／`flags` 無しの旧セーブも安全／チェック0件ではフィルターON不可
- **外部通信（fetch / XMLHttpRequest / sendBeacon）0件**
