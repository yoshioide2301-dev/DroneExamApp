## 2. 再開機能の仕様（`index.html` のみ・外部ライブラリ/通信なし）
- **LocalStorage キー**: `drone_exam_resume_state`（定数 `RESUME_KEY`）。
  `{ mode, license, index, ids:[問題ID...], cbtMode? }` のみを保存（個人情報・回答内容は保存しない）。
- **自動セーブ**: `renderQuestion()`（章別/章別誤答/ブートキャンプ/弱点/今日のおすすめ）と `renderCbtQuestion()`（CBT）の冒頭で `saveResumeState()`。問題が表示されるたびに上書き。
- **クリア**: `showResult()`（完走）、`finishCbt()`（CBT終了）、`abortCbt()`（CBT中断）、ポップアップの破棄操作。途中で「戻る」した場合は未完了として残す。
- **検証 `loadResumeState()`**: JSONの型・モード名・資格・index範囲・全問題IDの実在を確認。不正/破損データは破棄（ポップアップは出ない）。`lsGet/lsSet` と `try/catch` により localStorage 不可環境でも例外なし。
- **ポップアップ**（`#resumeModal`）: 起動時（`showResumePrompt()`）に有効なセーブがある場合のみフェードイン表示。🕒アイコン（オレンジのグラデ円）、文言「前回の設定があります／前回と同じ設定でトレーニング（学習）できます。内容をご確認ください」、資格・モード・進捗（例: `一等 ／ 一等計算特訓 ／ 3 / 80 問目から`）、横長オレンジグラデの「再開する」ボタン。`max-width:360px`・`overflow-wrap:anywhere`・文字サイズ連動でスマホ幅でも崩れない。
- **キャンセル導線**: 外側タップ／右上「×」／「最初から解く」→ `discardResume()` でセーブ破棄しメインメニューを表示。
- **再開 `applyResume()`**: `setLicense()` → モード・出題順（保存IDから復元）・インデックスを復元し、既存の `.screen` フェードで該当問題へ即遷移。既存の誤答ID管理・`cbt_exam_history`・SVGグラフ・ブートキャンプには手を入れていない（CBTは `startCbt()` の本体を `beginCbtSession(questions, index)` に切り出しただけで挙動不変）。

## 3. 仕様上の留意点
- 保存対象は依頼どおり最小限のため、**再開時の正解数カウントは0から**（問題ごとの誤答記録は従来どおり即時保存されるので学習履歴は失われない）。
- **CBT模擬試験は同じ問題セット・同じ問題番号から再開するが、回答済みの選択と残り時間は復元されず、タイマーは新規に開始**される（依頼の保存項目に含まれないため）。

## 4. 検証
- `<script>` 全2ブロックの構文チェック（`new Function`）OK。
- 疑似DOMでの起動シミュレーション: セーブ無し→ポップアップ非表示 / ブートキャンプ2問進行後の再起動→ポップアップ表示（3/80問目）→再開でindex=2・quiz画面 / 破棄でキー削除 / 破損・範囲外データ→非表示かつ削除 / 章別・CBTの保存→復元。
- 外部通信: シミュレーション中の `fetch`/`XMLHttpRequest`/`sendBeacon` 呼び出しは **0件**。再開機能自体に通信コードはなし（既存の `REMOTE_REVISION_URL` は空、報告フォームはプレースホルダー間モック動作）。
