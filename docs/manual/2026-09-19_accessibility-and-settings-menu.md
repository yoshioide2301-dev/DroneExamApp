## 2. アクセシビリティ
### 2-1. 文字サイズ（`drone_app_font_size` = `"100"|"120"|"140"`）
- 実装方式: CSS変数 `--fs`（1 / 1.2 / 1.4）。全ての `font-size:Npx` を `calc(Npx * var(--fs))` に一括変換（CSS・インラインstyle・SVG `font-size` 属性→`style`）し、`html{font-size:calc(16px*var(--fs))}` で継承文字も連動。問題文・選択肢・解説・学習資料の大型図表（SVG内文字含む）まで連動。
- ヘッダー右上の「A」ボタン（`cycleFontSize()`）で 標準→中→大→標準 と循環。ボタンには現在段階を表示。
- **新規CSSを書く時のルール**: フォントサイズは `font-size:calc(Npx * var(--fs))` で書くこと。

### 2-2. 背景テーマ（`drone_app_theme_mode` = `"light"|"medium"|"dark"`）
- `:root[data-theme="light|medium"]` がCSS変数を上書き（dark は従来の既定値）。ボタン（`cycleTheme()`）は ☀️→☁️→🌙 の順に循環しアイコンも連動。
- 色設計: 白オーバーレイは `rgba(var(--w),α)`（darkは `255,255,255`、light/mediumは濃紺系）に置換して自動反転。文字色は `--fg`、金色は `--gold`、警告色は `--warn`（light系は視認性のため濃色）、`color-scheme` は `--scheme`。下部バーのグラデーションは `--bg-rgb`。
- **意図的に固定した色**: 有色背景上の白文字（主ボタン・選択中タブ・トースト・正誤バッジ等）と、学習資料の図表カード（`.vis`／SVG）は全テーマで濃色カードのまま（自前配色で常に可読）。
- 起動時のちらつき防止のため、`<head>` に保存値をすぐ反映する小さなインラインスクリプトを追加。以降の処理は本体スクリプトの `syncDisplayUI()`。
- CBTグラフのSVGも `style` 経由でテーマ変数（`--w` / `--navy-top`）に追従。

## 3. ⚙️設定メニュー（`#settingsSheet`）
- 既存の報告用シートと同じ下からのハーフモーダル（`.sheet` + `.sheet-backdrop`）。「×」または背景タップで閉じる。背後のページのスクロールはロックしない。
- 【表示設定】テーマ（☀️/☁️/🌙）・文字サイズ（標準/中/大）をボタンスイッチで変更（ヘッダーのボタンと同期）。
- 【データ同期】
  - iCloudトグル（`drone_icloud_sync_enabled` = `"1"|"0"`）、紫（#6366f1）の「今すぐ同期」、ステータス「最終同期: YYYY/MM/DD HH:mm」（`drone_icloud_last_sync`。未実施は「未実施」）。
  - `syncWithiCloud()` は依頼どおりのプレースホルダー（1.5秒の疑似ローディング。ここにネイティブブリッジ `window.webkit.messageHandlers` 等の呼び出しを実装）。`handleSyncNow()` がスピナー表示→完了トースト「同期が完了しました」→最終同期時刻更新を担当。トグルOFF時は同期せず案内トースト。
  - 実際には何も同期していないため、UIに「現在はプレースホルダー動作」の注記を表示。
- 【サポート】
  - 「不具合・要望を送る」→ 既存の報告シート（Googleフォーム連携）を再利用。問題画面外から開くため `openReport(true)` を追加し、問題IDには `(設定メニューより)`、「どこの誤り」は「その他」を初期選択。通常の解説内ボタンの挙動は従来どおり（`reportQid`）。
  - 「アップデート情報」子アコーディオン＋NEWバッジ。開くと `drone_update_seen` に版数を保存してバッジを消す。内容は実際の直近変更に沿った静的テキスト（※依頼文の「教則第5版に完全対応」は、問題データ自体は全面改訂していないため「変更点5選を学習資料に反映」と表現）。
- 【アプリについて】「© Zero Gravity Films」「バージョン 1.1.0」。`APP_VERSION` を `1.1.0` に更新（報告フォームに送る版数も連動、表示は `APP_VERSION` から反映）。
- トーストの `z-index` を 60→90 に引き上げ（シート/モーダルの上に通知が出るように）。
