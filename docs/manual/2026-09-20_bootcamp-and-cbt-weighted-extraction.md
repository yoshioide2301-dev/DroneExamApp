# 技術履歴: 一等「計算問題集中特訓（ブートキャンプ）」と CBT模擬試験の重み付け抽出

最終更新: 2026-09-20

## 概要
`index.html` に、(1) 一等専用の計算問題集中特訓モード、(2) 一等CBT模擬試験の出題内訳の固定化（計算・リスク管理を全体の10%）を追加。二等の抽出ロジックは従来と同一。問題データ・LocalStorage キー・既存UIは変更なし（変更はロジック追加と表示のみ）。

## 1. ブートキャンプ（`state.mode = 'bootcamp'`）
- **UI**: 「問題演習」ペインの章一覧の下（`#bootcampWrap`）に、オレンジ→赤（`#ff9800`→`#f44336`）のグラデーションのボタン「🏋️ 一等計算問題集中特訓（ブートキャンプ） ／ 🧮 計算・リスク管理 全N問 ⚡️」。**一等選択時のみ表示**（二等では非表示）。`renderBootcamp()` を `setLicense()` / `backToMenu()` / 初期化で呼ぶ。文字サイズ連動のため CSS は `calc(Npx * var(--fs))`、ラベルは `min-width:0` で折り返し（スマホ幅・文字サイズ「大」・ライトテーマで目視確認）。
- **抽出（`startBootcamp()` / `bootcampPool()`）**: `licenses` に `"first"` を含み `category === "計算・リスク管理"`（現在 **80問**。依頼文の76問は実数と異なる。表示は実数から動的に出す）を**全問**出題。順序は「誤答履歴にある問題を先頭（ランダム）→残りをランダム」の苦手優先。二等では起動しない（ガード）。
- **表示**: クイズ上部 `🔥 一等計算特訓ブートキャンプ（全N問）`、結果画面 `🔥 一等計算特訓 完了`、「もう一度解く」で再開始（`retryChapter()` に分岐追加）。
- **流用**: 正誤判定・誤答履歴の登録/消去・進捗・解説/出典・章別誤答消去のゴールド判定は既存の `renderQuestion()` / `selectChoice()` / `recordAnswer()` をそのまま使用（新規のLocalStorageキーなし）。

## 2. CBT模擬試験の重み付け抽出（`cbtPlan()` / `buildCbtQuestions()`）
- 定数: `CALC_CATEGORY = "計算・リスク管理"`、`CBT_CALC_RATIO = 0.1`。
- **一等**: ① 計算・リスク管理からランダムに `round(n×0.1)` 問を固定抽出（本番50問→**5問**、ミニテスト10問→**1問**）。② 残り（45問／9問）は計算・リスク管理**以外**から、誤答履歴を最大30%枠（`floor(残り×0.3)`＝13問／2問）に強制注入（計算・リスク管理以外の誤答のみ対象）。③ 残りをランダム補完。④ 全体をシャッフル。
- **二等**: 従来と同一（プール全体から、誤答履歴を `round(n×0.3)`＝15問に強制注入して補完）。二等プールには計算・リスク管理（一等専用）は存在しないため混ざらない。
- 模擬試験タブの概要表示にも反映（一等: 「内訳：計算・リスク管理 5問（固定）＋ 文章問題 45問」「最大13問を優先出題」）。
- ミニテスト（10問）は依頼に明記が無いが、同じ10%基準で1問固定とした。

## 検証（モック環境・乱数500回の反復）
- ブートキャンプ: 計算・リスク管理の一等問題が**100%（80/80、重複なし）**、誤答の計算問題が先頭・文章問題の誤答は混入しない、正解で誤答履歴から消去/不正解で登録、結果タイトル、再挑戦、二等ではボタン非表示かつ起動不可。
- 一等CBT50問: **500回すべてで計算・リスク管理がちょうど5問**、常に50問・重複なし・一等問題のみ・二等専用(2-H)は混入せず、誤答（文章問題）の強制注入は最小16問（下限13を満たす）。誤答リストが空でも5問固定。ミニテスト10問は300回すべて1問。
- 二等CBT: 500回すべて50問・重複なし・二等問題のみ・計算・リスク管理0問、誤答の強制注入は従来どおり最小15問、10問モードも問題なし。
- 回帰: `cbt_exam_history`・誤答/進捗/試験日の読み込み後不変、章別誤答消去、学習資料、設定メニュー、CBT一連（時間切れ・採点・履歴・グラフ）が全て通過。`node --check` OK。差分の削除行は `renderCbtInfo` / `buildCbtQuestions` の書き換え分のみ。

## 留意点
- 既存の別カテゴリ「計算問題」（両資格共通の少数の問題）は、依頼どおり `"計算・リスク管理"` のみを計算問題として扱うため、模擬試験の文章問題枠に含まれる。
- ブートキャンプの全80問は長い。途中で「戻る」でも進捗（誤答履歴・解答済み）は都度保存される。
