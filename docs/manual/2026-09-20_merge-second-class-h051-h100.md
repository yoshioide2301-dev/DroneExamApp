# 追記: ハイブリッド時系列履歴ドットバッジ（問題ごとの直近3回の勝敗）

- **保存**: LocalStorage `drone_question_dots` = `{問題ID:[1|0,…]}`（1=正解, 0=不正解、古い→新しい、最大3件）。`recordAnswer()` の先頭で `pushDot()` を呼び、`slice(-3)` により4回目以降は最古を押し出す。`recordAnswer()` は章別/ブートキャンプ/弱点/今日のおすすめ（回答直後）とCBT（試験終了時の採点）の両方から呼ばれるため、全モードで記録される。外部通信なし。`loadDots()` は破損データ・不正値（0/1以外）・4件超を正規化して無視/切り詰め。
- **表示**: 問題文（通常・CBT）の右上に `.q-dots`（6px の丸、間隔4px、左=古い→右=新しい）。正解=フレッシュグリーン `#6fe08a`、不正解=イエローオレンジ `#ffb454`。初見の問題は一切表示せず、表示時のみ問題文の右に余白（`.has-dots`）を確保して文字と重ならない。通常モードでは回答直後にドットが1つ増える。CBTでは出題画面に「過去の履歴」を表示し、今回の結果は終了時の採点で記録される（次回以降のドットに反映）。
- **検証（疑似DOM）**: 初見=非表示／正解→[緑]／誤答→[緑,橙]（左から右へ増加）／[緑,橙,緑]／4回目で最古が押し出され[橙,緑,橙]／再起動後にLocalStorageから100%復元／一等・二等のCBTで出題時表示・終了時記録／破損データ耐性／外部通信0件。既存の再開・見直し・グラフ検証もすべてPASS。実ブラウザでの見た目（ドットの位置・テーマ別の視認性）は未確認。
