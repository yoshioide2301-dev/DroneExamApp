# 技術履歴: 学習資料タブ（改正ポイント）と法改正検知シミュレーション

最終更新: 2026-09-19

## 概要
`index.html`（単一ファイル・外部ライブラリなし）に「学習資料」タブと、教則改訂の擬似検知/適用ロジックを追加。既存の学習進捗・カウントダウン・おすすめ10問・報告フォーム連携のLocalStorage/ロジックは無変更。

## 1. タブ構成
- メニュー画面のヘッダー直下に `.tab-bar`（「問題演習」/「学習資料」）。`setTab(tab)` が `#practicePane` / `#materialsPane` の `.active` を切り替える。
- `#practicePane` には既存の一等/二等トグル・カウントダウン・おすすめ10問・進捗ゲージ・弱点モード・章一覧をそのまま格納（要素IDは不変）。
- スクロールは既存 `.app-content` のネイティブ縦スクロールのまま（固定/ピン留めなし）。

## 2. アコーディオン（用語集スタイル）
- データ: `amendmentData`（`id/title/trend/summary/visualType/visualContent`）。図表は `<table>` と基本図形SVG・div のみで構成したオリジナル表現。
- `renderAmendments()` が全件をカード描画、`toggleAccordion(id)` が `.open` をトグル。
- アニメーション: `.acc-body` の `grid-template-rows: 0fr → 1fr`（高さ自動対応のSlide Down/Up）。右端のChevron SVGは `.open` で `rotate(180deg)`。`aria-expanded` も更新。

### データ内容の修正（依頼文からの変更点）
- **amend_02**: 依頼文の「周囲概ね1,000m」を **「概ね300m」に修正**。小型無人機等飛行禁止法の周辺地域は敷地・区域の周囲概ね300mであり、1,000mは誤りのため（試験対策アプリで誤情報を出さないため）。
- **要確認**: amend_03（更新申請可能期間「6ヶ月前」）、amend_01（ⅡA/ⅡBの要件表）、amend_05 は、公式の最新資料（国交省 教則・技能証明の案内）で数値・表現を確認してから公開すること。

## 3. 自律リサーチ・法改正アップデート（擬似ロジック）
- LocalStorage: `droneKisokuVersion`（適用済み教則版数、既定 `"5.0"`。不正値は `5.0` 扱い）。
- `fetchRemoteRevision()`: プレースホルダー。定数 `REMOTE_REVISION_URL`（空）が設定されると `{"version":"6.0"}` 形式のJSONを取得。空の間は `null`（検知なし）。本番URLはコードにハードコードしない方針。
- `checkRemoteRevision()`: アプリ起動時と学習資料タブを開いた時に実行。リモート版 > 保持版なら `showUpdateBanner(version)`。
- バナー（`#updateBanner`、タブ直上）: 「【法改正検知】教則第N版…を適用しますか？」＋「適用する/あとで」。
- `applyUpdate()`: `droneKisokuVersion` を書き換え、表記を「教則第5版対応」→「最新：教則第N版（自律アップデート適用済）」へ動的変更（学習資料ヘッダー `#matHead`、メニューの準拠バナー `#kisokuBannerText`）。
- テスト用ボタン（学習資料タブ最下部）: 「強制発火」= `forceRevision('6.0')`、「第5版に戻す」= `resetKisokuVersion()`。
- **注意**: 現状の「適用」は版数表記の切替のみで、`QUESTIONS` 本体や解説文の差し替えは行わない（各解説の出典表記は `EDITION` のまま）。実データ更新の仕組みは別途設計が必要。

## 検証
- `<script>` を抽出し `node --check` で構文OK。
- モックDOMで、アコーディオン5件の描画、強制発火→バナー表示→適用→LocalStorage/表記更新、開閉トグル、リセットを確認。
- 実ブラウザでの目視確認（アニメーション・SVG表示・スマホ幅）は未実施。

## 追記: ファクト修正・デバッグUI隔離（2026-09-19）
一次情報（国交省 教則第5版）に基づく依頼を受け、以下を修正。なお本アプリの作成者側で一次資料との突合は未実施のため、公開前に数値を再確認すること。

### `amendmentData` の修正
- **amend_02**（重要施設周辺）: 禁止範囲を「おおむね300m → おおむね1,000m（約1km）」へ拡大した**最新の法改正**として記述。タイトル・解説・SVG内の数値を1,000mで統一（前回の「300m」への独断修正は撤回）。
- **amend_03**（技能証明更新）: 更新申請可能期間を「満了日の6ヶ月前から**1ヶ月前まで**」に修正（1ヶ月を切ると申請不可）。
- **amend_05**（工業専用地域）: 誤記「例外なしで許可必須」を全面書き換え。都市計画法上の工業専用地域の上空は、DID該当でもDIDに係る許可・承認が**不要（免除）**という**緩和措置**（工場地帯等での点検飛行の円滑化、教則第5版より引用）として、解説・HTML構造を差し替え。

### デバッグUIの隔離
- 資料タブ最下部の `.mat-debug`（背景 `#1a233a` / 文字 `#64748b` の目立たない小セクション）に、「【開発者用デバッグ】自律リサーチ（教則第6版検知）のモック発火」と「第5版の状態に戻す」のみを配置。通常表示では第5版表記のまま、第6版表記は発火・適用後にのみ出る。
- **実データ切替の仕組み**: `amendmentDataV6Sim`（シミュレーション用ダミー）を追加。`renderAmendments()` は `droneKisokuVersion` が `5.0` 以外のとき各項目の `trend/summary/visualContent` をダミーで上書きして描画し、`5.0` に戻すと第5版の解説に復帰する。`renderKisokuVersion()` が毎回 `renderAmendments()` を呼ぶため、適用/リセット/起動時に自動反映される。
- 既存の進捗・カウントダウン・報告フォーム連携のLocalStorage/ロジックは無変更。
