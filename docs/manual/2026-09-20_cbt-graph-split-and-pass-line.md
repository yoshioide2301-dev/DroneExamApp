# 技術履歴: 成長グラフの本番・ミニ分離 ＆ 合格ライン点線

最終更新: 2026-09-20

## 概要
`index.html` のみ変更（外部ライブラリ・通信なし）。`cbt_exam_history` のキー名・既存レコードは変更せず、新規保存分に `mode` を追記するだけの後方互換な拡張。

## 1. 履歴の2系統分離
- 保存: `finishCbt()` が `{date, total, correct, mode:'full'|'mini'}` を保存（`total` は従来どおり回答総数）。
- 判別 `cbtRecordMode(r)`: `mode` があればそれを採用。**旧履歴（modeなし）は `total <= 10` ならミニ、それ以外は本番**と自動分類（既存データの書き換えはせず、読み出し時にのみ判別）。
- `renderCbtGraph()`: 選択中の `cbt.mode` のレコードだけを抽出して直近5回を描画。`setCbtMode()` からもグラフを再描画するので、タブ切替でリアルタイムに出し分け。履歴が無いモードは「まだ○○の試験履歴がありません」を表示。タイトルにモード名を表示。

## 2. 縦軸スケール
- 上限 `MAXV = CBT_MODES[mode].count`（本番50 / ミニ10）。目盛りは上限を5等分（本番 0,10,…,50 ／ ミニ 0,2,…,10）。ミニでは10点満点の小さな伸びが大きく描かれる。

## 3. 合格ライン
- `<g id="cbtPassLine" data-pass="40|8">` 内に `<line stroke="#ff9800" stroke-dasharray="4,4" opacity="0.6">` を1本（Y座標＝合格正解数 40／8）と、右端に `<text fill="#ffb74d">合格ライン (80%)</text>` を動的注入。

## 4. 留意点
- 旧履歴で「本番で10問以下しか回答せず終了した」記録はミニに分類される（回答総数しか残っていないための限界）。以降の新規記録は `mode` で正確に分類される。
- 初期ダミー3件（回答35/45/50）は本番グラフに表示される。
