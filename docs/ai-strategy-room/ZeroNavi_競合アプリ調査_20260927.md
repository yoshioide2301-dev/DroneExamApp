# ZeroNavi 競合アプリ調査

調査日：2026-09-27
対象：日本のApp Storeに公開されている無人航空機操縦者技能証明・学科試験対策アプリ
目的：ZeroNaviの公開前後の市場ポジション、機能差、無料公開戦略、改善優先順位を整理する。

## 1. 調査上の前提

- App Storeの表示内容・評価件数・問題数・価格等は2026-09-27時点の確認値であり、今後変動する。
- 競合アプリが「公式」「過去問」と表示していても、その意味や出典は各アプリの記載に従い、ZeroNavi側では公式アプリであるかのような表現を行わない。
- 国土交通省は2026年7月14日から学科試験を「無人航空機の飛行の安全に関する教則（第5版）」に準拠すると案内している。ZeroNaviも公開版は第5版への整合を最優先とする。

## 3. 競合から確認できる市場傾向

### 問題数
500～800問級が既に存在する。一方、問題数だけを増やしても、本試験との難易度差・出題の網羅性・解説品質への不満が生じ得る。ZeroNaviはまず「368問→一等100問欠番解消→検証済み問題の品質確保」を優先する。

### 無料モデル
無料＋App内購入、完全無料、買切り、サブスクリプションなど複数モデルが存在する。したがってZeroNaviが当面無料で公開し、利用者300人程度まで実利用・バグ報告・改善を行ったうえで課金開始を判断する方針は、市場の既存モデルから大きく外れてはいない。

### 学習体験
単なる問題集から、弱点復習、模試、学習計画、忘却曲線、成績分析、教則参照まで広がっている。ZeroNaviにも既に弱点・誤答・模試・履歴・試験日等の機能があるため、今後は機能追加よりも「使いやすさ」「正確さ」「継続しやすさ」の検証を重視する。

### レビューから得られる示唆
競合レビューでは「問題が本試験より易しい」「未出題問題だけを解けない」「文字が途中で切れる」など、問題量ではなく実際の学習体験に関する不満が確認できる。ZeroNaviのベータ期間では、これらを重点的にテストする。

## 4. ZeroNaviの差別化候補

1. 一等・二等を一つのアプリで扱う。
2. 一等問題を100問揃え、連番欠落を解消する。
3. 教則第5版を基準に、問題・正解・解説・参照箇所を検証する。
4. 「ひっかけ問題」に偏りすぎず、正答根拠まで理解できる解説を維持する。
5. 弱点・誤答・模試・学習履歴など既存機能を、利用者の声を基に改善する。
6. 無料公開期間を「β運用」として扱い、バグ報告・離脱ポイント・学習継続率を収集する。
